DSA Lab 3: Queue (Pharmacy Queue and Bus Stop Priority Queue)

## Description
Two problems solved with a queue (FIFO) built from scratch using a linked list
(no built-in list or deque):

1. **Pharmacy queue:** add a customer (name and medicine), serve the first
   customer, and display the queue.
2. **Bus stop with priority:** two queues, one for passengers over 65 and one
   for everyone else. Boarding takes from the priority queue first.

## Files
- `lab3.py`: the code (Node, Queue, Pharmacy, BusStop, tests, menu)
- `DSA_LW3_Report.docx`: the lab report

## Notes
- Passengers older than 65 get priority (age > 65), so a 65-year-old is in the regular queue.
- enqueue and dequeue are O(1) thanks to the head and tail pointers. Displaying a queue is O(n).
